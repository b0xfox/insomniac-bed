# Insomniac Bed

## Features:

### Insomniac Beds
- Adds 16 new Insomniac bed variants.
- Insomniac beds can be laid in, but will not trigger a time reset reguardless of settings.

### Bed Command
- Use /bed to customize vanilla bed and Insomniac Bed behaviors.
- Settings are per-player.
- Running just /bed will list current settings.
- The `darkness` sub-command will enable/disable the darkness overlay when sleeping.
- The `advance_time` sub-command will enable/disable sleep time advancement. Meaning sleep is infinite in duration.
- The `limits` sub-command will enable/disable sleeping restrictions for vanilla beds.
- The `gui` sub-command will enable/disable the Leave Bed UI. When disabled, sneak to exit a bed.
